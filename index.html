Google 스프레드시트 실시간 연동

교실 구글 스프레드시트의 날짜별 역할 배정표를 웹 대시보드와 직접 연결합니다.

  1. 스프레드시트 준비: 구글 시트에 번호, 학생이름, 역할명, 수행시간, 수행여부 열을 작성합니다.
  2. 웹에 게시(Publish to web): 구글 시트 상단 메뉴 [파일] → [공유] → [웹에 게시]를 클릭합니다.
  3. CSV 형식 선택: 게시 형식에서 [웹페이지] 대신 [쉼표로 구분된 값(.csv)]을 선택하고 [게시]를 누릅니다.
  4. 링크 붙여넣기: 복사한 CSV 주소를 아래 입력창에 넣고 [지금 동기화 실행]을 누르면 즉시 연동됩니다!
* 일반 편집 URL (https://docs.google.com/spreadsheets/d/아이디/edit)을 입력해도 자동으로 CSV 내보내기 링크로 변환 시도합니다.

스프레드시트 템플릿 및 내보내기

구글 스프레드시트에 새로 만들 때 사용할 수 있는 표준 템플릿과 현재 수행 결과 다운로드입니다.

버튼을 누르면 현재 28명 학생과 역할 목록이 탭으로 구분된 형식으로 클립보드에 복사됩니다. 새 구글 시트의 A1 셀에 Ctrl+V로 바로 붙여넣을 수 있습니다.

웹에서 학생이 완료를 누르면 구글 시트에도 자동으로 실시간 기록되도록 하려면 아래 Apps Script를 시트 확장 프로그램에 추가할 수 있습니다:

function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = sheet.getDataRange().getValues(); return ContentService.createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); }
